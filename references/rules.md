# 解卦规则

## 数字卦一爻动的基本读法

数字卦只有一个动爻，读法固定：

| 卦 | 代表 | 读什么 |
|----|------|--------|
| 本卦 | 当前处境 | 卦辞 + 大象，定整体格局 |
| 动爻 | 事情的关键与当下要做的事 | 爻辞，**权重最高** |
| 互卦 | 事情发展的中间过程、内在隐情 | 卦义，见下文"互卦读法" |
| 变卦 | 事情的走向、结果 | 卦辞，看趋势不看定论 |

优先级：动爻爻辞 > 本卦卦辞 > 变卦卦辞 > 互卦。互相矛盾时以动爻为准。

## 爻位含义（辅助判断）

- 初爻：事之始，位卑，宜潜藏、准备
- 二爻：得中，下卦之主，多吉；对应"臣位"、执行者
- 三爻：下卦之顶，多危，处于过渡与抉择
- 四爻：近君位，多惧，需谨慎
- 五爻：得中，上卦之主，尊位，多吉
- 上爻：事之终，多亢、多变，要考虑收尾与退场

阳爻居阳位（初三五）、阴爻居阴位（二四上）为"当位"，一般顺；否则"不当位"，多有波折。这只是辅助，不能压过爻辞本身。

## 互卦读法

互卦取本卦的二、三、四爻为下卦，三、四、五爻为上卦。它不含初爻和上爻，也就是去掉了"开头"和"结尾"，剩下的是事情**中间的过程**，以及当事人和相关方**内在的、没摆到台面上的状况**。

读互卦回答三个问题：

1. **过程顺不顺**：互卦卦义偏顺（如复、渐、家人、既济）说明中途推进平稳；偏阻（如蹇、剥、大过、未济）说明中间有一段要熬。
2. **内情是什么**：互卦常揭示表面看不到的动因。本卦好而互卦差，说明局面好看、里面有隐患；本卦差而互卦好，说明表面难看、内里有转机。
3. **和变卦是否同向**：互卦与变卦同向，趋势判断可以说得更确定；互卦与变卦反向，要提醒中途会有反复，结果不能一锤定音。

互卦只有 16 种可能，各自对应的"过程"含义：

| 互卦 | 过程含义 |
|------|----------|
| 乾为天 | 过程刚健、要一直用力，阳气足但易过刚 |
| 坤为地 | 过程平顺、需要顺势承载，主动性弱 |
| 水火既济 | 中途已经成形，各方到位，但要防守成后松懈 |
| 火水未济 | 中途尚未成形，事情还在路上，需要继续推进 |
| 地雷复 | 中途有回转、重来的机会，一阳初生 |
| 山地剥 | 中途在被削减、损耗，根基有动摇 |
| 山雷颐 | 中途关键在养、在补给，看资源够不够 |
| 泽风大过 | 中途负担过重，压力大，要减负 |
| 天风姤 | 中途有意外的相遇或介入，多是外来因素 |
| 泽天夬 | 中途要做决断、有取舍，需要果断 |
| 水山蹇 | 中途遇阻难行，靠自己硬走不通，要借力 |
| 雷水解 | 中途困局解开、松动，转向缓和 |
| 风山渐 | 中途循序渐进，慢但稳 |
| 雷泽归妹 | 中途不够正、仓促将就，有勉强成事的意味 |
| 风火家人 | 中途靠内部协调、各守其位，讲的是分工和秩序 |
| 火泽睽 | 中途有分歧、不合，需要在差异中求同 |

在"趋势判断"一段里，用一两句话把互卦的过程含义放进"本卦 → 互卦 → 变卦"的链条里，不单独展开。用户追问时再详说。

## 卦辞中的断语

- 元吉 > 大吉 > 吉 > 无不利 > 无咎 > 无悔 / 悔亡
- 吝（小麻烦） < 厉（危险，需警惕） < 悔 < 凶
- 利贞：守正才有利；贞吉：坚持正道则吉；贞凶：固守不变会凶
- 利涉大川：可以冒险行动；不利涉大川：不宜冒进
- 利见大人：宜寻求有能力者的帮助
- 亨：通达，过程顺利，不等于结果一定好

## 三种视角的定位（用于 SKILL.md 的"三法汇解"）

1. **经文本义**：只基于 hexagrams.json 里的原文，说清字面意思。
2. **直断视角**（参照高岛易断的风格）：把卦爻辞直接落到所问之事上，给一个明确的吉凶走向判断。注意：本 skill 不含《高岛易断》原文，只借用其"直接断事"的方法，不得伪造引文。
3. **生活易理视角**（参照傅佩荣的讲法）：把卦义翻译成当事人的处境、心态和该做的选择。同样不得伪造引文，只表述方法。

## 不该做的事

- 不得把"变卦吉"直接等同于"事情一定成"。变卦是趋势，动爻才是关键。
- 不得因为本卦名字听起来好或坏（如"否"、"困"、"大有"）就下定论，先读爻辞。
- 对医疗、法律、投资、重大人生决定，只提供思考角度，明确建议咨询专业人士。
