# 开始之前，先聊两分钟

**这是个什么东西**

数字卦，《周易》里最省事的一种起卦法。你随手写三组三位数，我用它们算出一个卦和一条"动爻"，然后把对应的原文翻出来给你看。不用铜钱，不用蓍草，不用先啃完《周易》，几分钟搞定。

**它能帮你什么，不能帮你什么**

不能：预测未来、替你做决定、告诉你彩票号码。

能：你在一件事上卡住了、来回纠结的时候，借一段两千多年前的话换个角度看自己。很多时候答案你心里已经有了，卦只是帮你把它说出口。

**怎么起卦**

1. 找个安静点的地方，别一边刷视频一边占。花半分钟，把要问的事在心里过一遍。
2. 用一句话把问题说具体。
   - 好的问法：「这次跳槽去 A 公司，近半年会顺吗」
   - 不好的问法：「我今年运气怎么样」（这个卦答不了，太大了）
3. 心里想着这个问题，随手写三组三位数，比如 372、815、246。不要挑，不要算，第一反应是什么就写什么。不知道怎么"随手"？闭眼想着问题，脑子里蹦出什么数字就写什么；或者看一眼手机时间、路边车牌、手边书的页码，随便抓三个。
4. 把问题和三组数字告诉我，剩下的交给我。

**什么事适合问**

- 一次只问一件事。想问两件，就起两卦。
- 具体的、近期的、你自己能做点什么的事，最合适。
- 结婚、大额投资、看病、打官司这类大事，不建议用卦来定。找专业的人，卦最多给你一个思考角度。

**三不占（老规矩，得守）**

- **不诚不占**：抱着"我看你准不准"的心态来，别占。它不是来跟你打赌的。
- **不义不占**：坑人的事、亏心的事，别占。
- **不疑不占**：已经想清楚了，别占；同一件事翻来覆去地问，也别占。第一卦就是答案。

**别迷信它**

孔子晚年迷周易，帛书《要》篇记他自己说「吾百占而七十当」：占一百次，对七十次。这是史上最会读易的人给出的成绩。所以别把卦当判决书，它给的是提醒和启发。看结果时多留意爻辞里说到的态度和做法，少盯着"吉"和"凶"那两个字。

**用它最好的方式**

把解卦当成和一位读过很多书的老朋友聊天。他不知道你的事会怎样，但会根据你说的情况，讲一段古人的话，再告诉你他从中看到了什么。听完，做决定的还是你。
