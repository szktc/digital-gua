# digital-gua

> 三个数字，一卦，两千多年前的老先生们给你一句话。

一个装进 AI 助手的数字卦 skill。你随手写三组三位数，说一件正在纠结的事，AI 帮你起卦、查《周易》原文、讲讲这卦想说什么。不用铜钱，不用蓍草，不用先读完《周易》。

适配 Kiro、Claude Code，以及其他认 `SKILL.md` 的 AI 编程助手。

**先说清楚：** 这不是算命。它更像一个换角度思考的工具，你带着问题来，古人给你一段话，怎么理解、怎么做，还是你自己决定。孔子自己说他占卦"百占七十当"，你就别指望更高了。

## 它长什么样

你说：

> 帮我算算，要不要接这个新项目。

AI 第一次会先跟你唠唠这东西是什么、怎么用、什么能问什么不能问（是的，有规矩，叫"三不占"），你说"了解，开始"，然后随手写三个数：

> 372、815、246

它就给你画出卦来，把原文摆出来，再用大白话讲一遍：

```
本卦 山雷颐（上艮下震）
上九 ▅▅▅▅▅▅▅  ← 动爻
六五 ▅▅▅ ▅▅▅
六四 ▅▅▅ ▅▅▅
六三 ▅▅▅ ▅▅▅
六二 ▅▅▅ ▅▅▅
初九 ▅▅▅▅▅▅▅
```

> 上九：由颐，厉吉，利涉大川。

翻译成人话：可以干，有点风险，但值得放手一搏。（具体到你的事怎么讲，AI 会展开。）

## 安装

前提：电脑上有 Python 3.8 或更新（终端里敲 `python --version` 看一眼）。不用装别的。

### 方式一：一行命令（推荐）

Windows，打开 PowerShell 粘贴：

```powershell
git clone https://github.com/szktc/digital-gua.git $env:USERPROFILE\.kiro\skills\digital-gua
```

Mac / Linux：

```bash
git clone https://github.com/szktc/digital-gua.git ~/.kiro/skills/digital-gua
```

用 Claude Code 的朋友，把路径里的 `.kiro` 改成 `.claude` 就行。以后想更新，进那个目录 `git pull`。

### 方式二：不想碰 git

页面右上角绿色 **Code** 按钮 → **Download ZIP**，解压，把文件夹名字里的 `-main` 去掉，改成 `digital-gua`，然后丢进下面对应的目录：

| 你用的工具 | 丢到这里 |
|-----------|---------|
| Kiro（全局，哪个项目都能用） | `~/.kiro/skills/digital-gua/` |
| Kiro（只在某个项目用） | `<项目>/.kiro/skills/digital-gua/` |
| Claude Code（全局） | `~/.claude/skills/digital-gua/` |
| Claude Code（只在某个项目用） | `<项目>/.claude/skills/digital-gua/` |

Windows 上 `~` 就是 `C:\Users\你的用户名`。在资源管理器地址栏输 `%USERPROFILE%\.kiro\skills` 回车就能直达；没有 `skills` 文件夹就自己建一个。

### 最后一步，很多人栽在这

装好以后**新开一个会话**。旧会话不认新 skill，不是你装错了。

## 怎么用

在 AI 助手里随便说一句：

- 帮我算算……
- 我想占一卦
- 周易 / 易经 / 数字卦 / 起卦 / 卦象……

或者直接甩三个数加一个问题。

流程是这样的：

1. **它先给你上课**（很短）：数字卦是什么、怎么起、哪些事适合问、三不占、为什么别迷信。
2. **你说"了解，开始"**，给一句具体的问题 + 三组三位数。
3. **它跑脚本起卦**，然后按固定格式讲：一句话总览、起卦过程（带图）、卦象校验、三种角度的解读、趋势、行动建议、风险提示。
4. **想追问就追问**：某句爻辞什么意思、别的线说了什么、换个角度看，都可以。

### 什么能问

具体的、近期的、你自己能做点什么的事。"这次面试 A 公司能过吗"是好问题，"我今年运气怎么样"不是，AI 会帮你把问题收窄。

### 什么别问

- 结婚、大额投资、看病、打官司这类大事。卦只能给你一个角度，请找专业的人。
- 不诚不占（"我看你准不准"这种心态，别占）
- 不义不占（坑人的事，别占）
- 不疑不占（已经想清楚了，或者同一件事翻来覆去问，别占）

## 不用 AI，直接跑脚本

想看看卦是怎么算出来的，或者就想查查某一卦的原文：

```bash
python scripts/cast.py 372 815 246                        # 起卦，吐 JSON
python scripts/cast.py 372 815 246 --order upper-first    # 第一组定上卦（另一种习惯）
python scripts/cast.py --lookup 水雷屯                     # 查一卦
python scripts/cast.py --lookup 3                         # 按序号查
```

## 它是怎么算的

傅佩荣数字卦法：

- 第一组 ÷ 8 取余数 → 下卦
- 第二组 ÷ 8 取余数 → 上卦
- 第三组 ÷ 6 取余数 → 动爻
- 余数是 0 就当 8（坤）或 6（上爻）
- 先天八卦数：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8

算数交给脚本，AI 只负责解读。这样它不会算错余数，也不会张嘴编一段不存在的爻辞。

## 文件都是干什么的

```
digital-gua/
├── SKILL.md                 # 给 AI 看的操作手册
├── README.md                # 你正在看的这个
├── scripts/cast.py          # 起卦、变卦、互卦、画图、校验
└── references/
    ├── intro.md             # 起卦前给你上的那堂课
    ├── hexagrams.json       # 64 卦原文：卦辞、大象、384 条爻辞
    └── rules.md             # 解卦规则：哪句话权重高、互卦怎么读、小白词表
```

## 几句要说明的

- `hexagrams.json` 里只有《周易》原文（公版）。解读风格参考了高岛易断和傅佩荣的路子，但**不含**他们的原文，AI 也被要求不许假装引用。
- 这是一个传统文化学习交流工具，所有内容仅供参考，不是预测，不是咨询，不能替代医疗、法律、金融、心理等专业服务。你的决定你负责，作者和这个工具不为使用后果背锅。不接受这条的话，请别用。
